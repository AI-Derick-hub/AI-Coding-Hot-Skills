Inclusion rules

Each entry is one public GitHub repository. It is listed when either rule is true:

  1. GitHub shows at least 2,000 stars.
  2. Stars are still below 2,000, but growth is fast: at least 100 new stars in 7 UTC calendar days and at least 10% of the current total, or at least 250 new stars in 30 days and at least 25%. The counts come from GitHub's daily star history. If they cannot be verified, the repository is not added.

A skill can have more than one category: Requirements, Development, Testing, Design diagrams, and Generate PPT. The files are data/skills.json and data/daily-report.json. This project does not use a database.

Static page generated from JSON in the repository. Machine-readable report: data/daily-report.json. Skill data: data/skills.json.
